# ホスティング比較（「URLを知る人のみ」運用）

運用方針：**URLを知る人のみが見られれば足りる**（パスワードは不要）。
ページには `noindex` と `robots.txt` を設定済みで、検索エンジンには載りません。

> 料金・条件は変わります。下の表は2026年10月に調べた内容で、**契約前に各社の公式ページで再確認**してください。
> 私が公式ページを直接確認できなかった項目は「要確認」と書いています。

## 比較表

| | GitHub Pages | Cloudflare Pages | Netlify |
|---|---|---|---|
| 費用 | 無料 | 無料枠あり | 無料枠あり |
| 無料でのリポジトリの公開範囲 | **Publicのみ**（Privateで使うには有料プラン） | Privateのリポジトリからも公開できる（要確認） | 可（要確認） |
| URLだけで運用（パスワードなし） | 可 | 可 | 可 |
| パスワード保護 | **不可**（無料では） | 可（Cloudflare Access。要設定） | 新しいアカウントでは**有料のProが必要** |
| 更新の手間 | GitHubにアップロードするだけ | GitHubにアップロードするだけ（初回に連携設定） | 同左 |
| 初期設定の難しさ | 易しい | 少しある | 少しある |
| 商用利用 | **無料枠は主に商用のサイト用途を想定していない** | 制限は緩い（要確認） | 無料枠の範囲内で可 |
| https | 自動 | 自動 | 自動 |

## 推奨

**今回は、GitHub Pages をおすすめします。**

- あなたはすでにGitHubアカウントをお持ちで、「ファイルをアップロードするだけ」の更新が、いちばん簡単です。
- 「URLを知る人のみ」で足りるなら、追加の設定は要りません。

### 知っておくべき点

1. **リポジトリが Public になります。** 検索すれば、地図のデータ（危険個所の位置と説明）が見えます。
   - 危険個所の情報は、安全のための情報で、秘密情報ではありません。ただし、「参加者限定」を厳密に守りたい場合は、次のどちらかにしてください。
   - A：Cloudflare Pages に移す（Privateのリポジトリから公開でき、必要ならパスワード保護も追加できる）。
   - B：GitHub Pro（有料）で、Privateのリポジトリから公開する。ただし、**公開されたサイト自体は、誰でも見られる**ままです。
2. **商用利用の注意。** GitHub Pages の無料枠は、「主に商用目的のサイトの無料ホスティング」を想定していません。今回は補助金事業のツアー参加者向けの利用です。
   - 将来、訪日向け商品（Japan Discovery シリーズ）の販売ページと一体で使う場合は、**Cloudflare Pages に移すこと**を検討してください。
3. **移行は簡単です。** このアプリは、ファイルをそのまま置くだけの作りで、どのサービスにも同じファイルを置けます。

## 参加者向けURLの運用

- 参加者に配る URL（QRコード）は、**`?edit=1` を付けない**ものにします。
- リポジトリ名は、推測されにくい名前にします（例：`dewa-map-2026-xk7`）。
- URLを、SNSなど不特定多数が見る場所に載せないでください。
- 万一URLが広まった場合は、リポジトリ名を変更すると、旧URLは使えなくなります（QRを作り直します）。
