# スマホでの確認手順と既知の制限

**公開したURL（https）で行ってください。** パソコンの `localhost` は、スマホからは開けず、現在地も使えません。

## 準備

- 公開URL（`?edit=1` なし）。
- テスト端末：iPhone（Safari）、Android（Chrome）。
- 電波のある場所と、電波のない状態（機内モード）の両方で確認します。
- 画面は、スマホの設定に合わせて**ライト／ダーク**になります。両方で見え方を確認してください。

## D. 編集画面（打合せ前のリハーサル）

1. パソコンで、`?edit=1` を付けて開く。画面のふちがオレンジになり、左に「編集メニュー」が出ることを確認する。
2. 「＋ 新しいピンを追加」→ 地図をクリック → 種別・危険度・内容を入力 → 「保存」。
3. 置いたピンを、ドラッグで動かす。ピンをクリックして直す。削除して、「元に戻す」で戻す。
4. 「種別・危険度の編集」で、アイコンと色を変える。
5. 「書き出し」で2ファイルを保存する。
6. GitHubの `data` に上書きアップロードし、スマホで反映を確認する（1〜3分後）。
7. （任意）スマホでも `?edit=1` を開き、下のメニュー中央の「＋」でピンを置けることを確認する。

## 既知の制限

### 現在地・GPS
- 現在地の取得には、**https接続**と**位置情報の許可**が必要です。
- 屋内、谷間、建物のそばでは、精度が低くなったり、取れなかったりします。精度の円の大きさを見てください。
- **接近の通知はありません**（第2段階の予定）。第2段階でも、通知は**画面を開いている間だけ**動き、iPhoneでは振動が使えません。**「通知があるから安全」ではありません。**
- 位置情報は、スマホの中だけで使い、外部には送りません。

### オフライン
- 保存されるのは、**参加者が見た範囲の地図だけ**です。見ていない範囲は出ません。
- **iPhoneのSafariは、サイトを長く（約7日以上）開かないと、保存内容を消すことがあります。** ホーム画面に追加したアプリは、この影響を受けにくくなります。**出発直前に、必ずオフラインで確認してください。**
- 端末の容量が少ないと、古い地図から消えることがあります（上限3,000枚）。
- アプリを更新したあと、スマホに反映されるのは、**次に電波のある場所で開いたとき**です。
- 国土地理院タイルの一括取得は行っていません。オフライン用の地図は、閲覧した分だけです。

### 地図
- 国土地理院の地図は、**ズーム18が最大**です（それ以上は、拡大表示になります）。
- 写真は、島の一部で古い、または雲がかかっている場合があります。
- ピンの位置は、入力した座標のとおりです。地図の位置ずれ（数m）はあり得ます。

### マイピン（利用者のピン）
- 保存先は、**その端末のそのブラウザの中だけ**です。ほかの人には見えません。ブラウザのデータを消すと、なくなります。
- みんなの地図に載せるには、**利用者が「運営に送る」→ 運営が確認して取り込む**、という手順が必要です（サーバーがないため）。
- 「共有する」は、スマホのブラウザ（https）で出ます。PCのブラウザなど、出ない環境では「コピーする」を使います。
- 「メールで送る」は、`data/config.json` にメールアドレスを入れたときだけ出ます。
- 危険個所は、利用者は追加できません（運営だけが登録します）。

### 編集
- 編集画面は、本物の認証ではありません。URLを知る人は誰でも開けます。ただし、公開版は書き換わりません。
- 編集内容は、**そのブラウザの中だけ**に保存されます。別の端末・別のブラウザには引き継がれません。**必ず「書き出し」をしてください。**
- 複数人の同時編集はできません。
- 写真は、アプリの中からアップロードできません（GitHubの `photos` に置きます）。
- 編集画面の表示は、日本語のみです（入力する内容は、日英の両方）。

### 表示
- 編集は、PC（画面共有しながら）での利用がいちばん使いやすい作りです。スマホでも、ピンを置いて入力できます。
